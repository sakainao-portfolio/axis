# 🏢 建築設計事務所 架空サイト

学習の一環として制作した、論理的な設計や持続可能な建築を求めるクライアントがターゲットの建築設計事務所の架空Webサイトです。

## 🔗 デモサイト
- 公開URL： https://sakainao-portfolio.github.io/axis/

## 🛠️ 使用技術
- HTML5 / CSS3

## 💡 工夫したポイント・設計
- **トンマナと配色:** コーポレートサイトとしてのクリーンなイメージや信頼感を表現するため、ホワイト（`#FFFFFF`）をベースに、ブルー（`#89A39E`）やネイビー（`#1C294A`）、アクセントカラーに高級感を演出するゴールド（`#D5B363`）を採用しました。
- **コード設計:** `outer` → `wrapper` → `article` の階層ルールを意識し、保守性の高いHTML/CSS構造を心がけました。
- **レイアウト:** 建築物の直線的な美しさに調和するよう、グリッドレイアウトにこだわってレイアウトしました。
- **ビジュアル・質感のこだわり:** 幾何学的な直線やガラスが美しい建築物の、高画質で明るい色合いとシャープな写真で統一し、洗練されたイメージや論理的（ロジカル）な美しさを表現しました。
